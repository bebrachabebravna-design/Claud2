# Подарок для Яры 🎁

Сайт открытка на день рождения. Открывается слой за слоем: коробка, поздравление,
обёрточная бумага, письмо, лента жизни по годам и финал с кодовым словом.

## Что где лежит

```
index.html              разметка всех шести слоёв
css/styles.css          вся красота и анимации
css/fonts.css           подключение шрифтов
fonts/                  сами шрифты, лежат в проекте
js/content.js           ТЕКСТЫ, имя, телеграм, кодовое слово  ← правь тут
js/audio.js             музыка и звуки (синтез прямо в браузере)
js/confetti.js          конфетти, сердечки, салют
js/app.js               логика переходов между слоями
photos/                 сюда кладём фотки 0.jpg ... 17.jpg
preview.png             картинка для превью ссылки в телеграме
```

Сайт полностью самодостаточный: никаких библиотек, сборки и запросов
наружу. Шрифты и звуки лежат внутри, музыка синтезируется браузером,
поэтому всё открывается мгновенно даже на плохом интернете.

## Как поменять тексты

Открой `js/content.js`, там всё подписано по русски:

- `CONFIG` — имя, возраст, ник в телеграме, кодовое слово
- `LETTER` — письмо, каждая строка в кавычках это отдельный абзац
- `MEMORIES` — подписи к каждому году в ленте

Тексты письма и подписей это черновики, их стоит переписать своими словами.

## Как добавить фотографии

Положить в папку `photos` файлы с именами `0.jpg`, `1.jpg` ... `17.jpg`,
где число это возраст на фото. Подробности в `photos/КАК_ДОБАВИТЬ_ФОТО.txt`.

Если фото нет, карточка покажет аккуратную заглушку, сайт не сломается.

## Как посмотреть локально

Просто открыть `index.html` двойным кликом. Или, если под рукой есть питон:

```bash
python3 -m http.server 8000
```

и зайти на `http://localhost:8000`.

## Как выложить на Netlify

**Способ 1, самый быстрый (без регистрации в гите):**

1. Скачать эту папку целиком к себе на компьютер.
2. Зайти на [app.netlify.com/drop](https://app.netlify.com/drop).
3. Перетащить папку в окно браузера.
4. Через несколько секунд Netlify выдаст ссылку вида `что-то.netlify.app`.
5. Ссылку можно переименовать в настройках сайта: Site configuration → Change site name.

**Способ 2, из репозитория:**

1. В Netlify нажать Add new site → Import an existing project.
2. Выбрать GitHub и этот репозиторий.
3. Build command оставить пустым, publish directory поставить `.`
   (это уже прописано в `netlify.toml`, так что скорее всего подставится само).
4. Deploy.

После деплоя фотки можно менять прямо в репозитории, Netlify пересоберёт сайт сам.

## Превью ссылки в телеграме

Когда кидаешь ссылку в чат, телеграм показывает карточку с картинкой
`preview.png`. Чтобы она точно подтянулась, после деплоя лучше открыть
`index.html` и в строке

```html
<meta property="og:image" content="preview.png">
```

заменить `preview.png` на полный адрес, например
`https://твой-сайт.netlify.app/preview.png`.

Работает и без этого, но с полным адресом надёжнее.

## Мелочи, которые стоит знать

- Музыка и звуки включаются только после первого касания экрана, это правило
  браузеров, обойти нельзя. Кнопка звука в правом верхнем углу.
- Кнопка в конце открывает телеграм с уже написанным сообщением.
  Ник задаётся в `js/content.js`, поле `telegram`.
- Сайт рассчитан в первую очередь на телефон, но на компьютере тоже работает,
  ленту там можно листать стрелками на клавиатуре.
- Точки сверху показывают, на каком слое находишься, по ним можно
  вернуться к уже открытым слоям.
